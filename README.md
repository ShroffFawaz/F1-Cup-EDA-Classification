# F1 Cup – Exploratory Data Analysis & Classification

## Overview
This project explores Formula 1 (F1) race data and applies machine learning classification to understand patterns in driver and race outcomes.  
The goal is simple: **analyze the data, build models, and visually compare how different classification algorithms perform.**

This repository is designed to be easy to understand, even if you are not from a technical background.

---

## What this project does
- Cleans and explores the F1 dataset to understand trends and patterns  
- Applies multiple **classification algorithms** to the same dataset  
- Compares model performance using **accuracy**  
- Builds and visualizes a **Decision Tree classification model**  
- Presents insights in a clear and visual way  

---

## Dataset
- The dataset contains Formula 1 race and driver-related information  
- Data is provided in raw form and used directly in the notebook  
- Basic cleaning and preprocessing steps are applied before modeling  

📁 Dataset file is included in this repository.

---

## Analysis Performed
### Exploratory Data Analysis (EDA)
- Checked data structure and missing values  
- Explored distributions of key features  
- Identified patterns useful for classification  

### Classification Models Used
- Logistic Regression  
- Decision Tree Classifier  

Each model was trained on the same data so results are easy to compare.

---

## Decision Tree Model
The project includes a **visualized Decision Tree** that shows:
- How decisions are made step by step  
- Which features influence predictions  
- Clear class separation at leaf nodes  

📌 The decision tree image is included in this repository for easy understanding.

---

## Model Comparison
- Accuracy of each classification algorithm is calculated  
- Results are visualized to show **Algorithm vs Accuracy**  
- Helps understand why some models perform better than others on this data
